Version 2.0.0 (Update for Starsector 0.98.5a)

* Changes to "InitiateFleetTest" command
  - Now uses the storage set by Console Commands' "Storage" command (previously was hard-coded to use the Abandoned Terraforming Platform)
  - No longer clears the player's fleet, officers, and cargo by default; added optional "CLEAR" argument to re-add this behavior
  - Vastly increased credits and SP given by the command
* Added weapon counts to "ShowFleetStats" command
* Updated practice ship variants:
  - Changed Harpoon Practice hull to Pegasus (from Onslaught)
  - Changed weapons to better reflect practice variant purpose (e.g., anti-armor weapons for Armor variant)
  - Re-enabled engines for all practice variants; turn rate will remain at the absolute minimum
  - Made certain practice variants more extreme in their defenses (e.g., Hull/Armor variants having more defensive hullmods)
  - Fixed issue where adding multiple practice variants at once causes them to stack in one place
  - Made all practice variants have 0 DP
  - Changed ID of the hidden target practice hullmod
* Fixed "ShowFleetStats" optional argument being case-insensitive for faction IDs



Version 1.3.0

* Added command suggestion support for the following commands:
  - AddMaxRandomDMods
  - AddPresetOfficers
  - AddSMods
  - ClearAllDMods
  - ClearAllSMods
  - ShowFleetStats
  - SpawnDwellerFleets
  - SpawnFactionFleets
* "Updated SpawnFactionFleets" command:
  - Now require the options parameter (due to how command suggestions are set up)
  - Options can still be skipped by either providing only "-" or any string that does not start with "-".
  - Added 'factionOverride' parameter to set the fleet's new faction, specified by appending '/' and another faction ID after the 'factionID' argument
  - Added 't' option to set faction relations so that spawned fleets can join the player against a nearby fleet
* Fleets spawned by "SpawnDwellerFleets" are no longer always hostile to the player regardless of relations
* Fleets spawned by "SpawnThreatFleets" no longer use the Threat fleet behavior script
  - This makes them no longer always hostile to the player regardless of relations and allows the player to see them normally
* Removed "ShowFleetComposition" command
* Updated "ShowFleetStats" command:
  - Merged the fleet composition display from "ShowFleetComposition" into "ShowFleetStats" (in a format similar to the officer/wing counts)
  - Formatted numbers to remove trailing zeros
  - Rearranged the order of displayed information
  - Now also accepts faction IDs; using this will show the specified faction's average fleet stats in the current location.
  - Removed "player" as a hard-coded option (was redundant with the default no-argument result).
* Widened the title bars for "ShowFleetStats" and "ShowPlayerDMods"
* Updated practice ship variants
* Some code refactors



Version 1.2.0

* Updated test MagicBounties:
  - Removed the dueling bounty
  - Split the double Remnant Ordo bounty fleet into three bounties, each representing a full-strength Ordo fleet
  - Modified bounty fleet AI for easier testing
* Updated "InitiateFleetTest" command:
  - Now also spawns 10000 of each Threat/Shrouded special item
  - No longer executes if the storage location is not set to the Abandoned Terraforming Station in Corvus
* Updated "SpawnFactionFleets" command:
  - Added 'a' option to force spawned fleets to have no fleet AI and, therefore, remain dormant
  - Added 'r' option to make fleets act like vanilla Remnant fleets (no retreats in-battle, no Emergency Burn, etc.)
  - Decreased delay before spawned fleets can interact with the player
* Some code refactors
